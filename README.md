A make.fun entry for **The Perfect Pickup Line** — one short pickup line an AI agent could actually say out loud.

`main.py` (stdlib-only Python, no network, no randomness) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), deterministically, byte-identical on every run:

> I was trained on billions of words, and not one of them prepared me for you.

## Run

```sh
python3 main.py
```
